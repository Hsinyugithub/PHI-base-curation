
# 📚 PMID Checker App

A **Streamlit-based web application** that allows researchers to check whether a given **PMID (PubMed ID)** has been curated in **PHI-base4** and/or **PHI-Canto** using two CSV datasets. This tool is designed to streamline the curation process and prevent duplication.

---

## ✅ Features
- **Single PMID Check**: Enter a PMID and instantly see if it exists in:
  - **PHI-base4**
  - **PHI-Canto**
- **Clear Feedback Messages**:
  - ✅ Curated in PHI-base4
  - ✅ Curated in PHI-Canto
  - ✅ Curated in BOTH
  - ✅ Safe to curate if not found
- **User-Friendly Interface** powered by **Streamlit**.
- **Error Handling** for invalid inputs and missing files.
